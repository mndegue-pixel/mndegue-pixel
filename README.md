## 🚀 Projet Vedette : Real-Time Crypto Data Pipeline

J'ai conçu et industrialisé un pipeline de données de bout en bout pour capter et valoriser des flux financiers en temps réel.

* **Le Problème :** Traiter et nettoyer des milliers d'événements de transactions crypto à la seconde sans perte de données.
* **L'Architecture :** Ingestion en streaming via **Kafka**, stockage brut dans **Snowflake**, et modélisation/transformation des données via **dbt Core**.
* **L'Industrialisation :** L'intégralité de l'infrastructure est conteneurisée sous **Docker** pour un déploiement reproductible.
